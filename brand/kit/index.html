Two marks in review

Sprout Studio and Peek share everything except the mark and the type. Pick one, pick a palette, and every section below follows.

01

Logo

The horizontal logo is the default. Use the stacked one where width is tight, and the mark alone where the name is already shown nearby.

02

Space and size

Keep clear space of one antenna height (a quarter of the mark) on every side. Below 24 px use the mark alone.

03

Colour

Every palette has the same roles, so swapping palettes never breaks a layout. Contrast ratios are checked against WCAG 2.

04

Type

One display face for headings and the wordmark, one text face, and a mono for labels, versions and code.

05

Emotions

The antennae and eyes do the acting. Each emotion has a job, so the character always means something when it appears.

06

Motion

Things land, squash a little and settle, the way a good jump feels. Nothing slides in flat.

07

In use

The same parts on the places people actually meet you.

Please don't

The mark only works if it always looks like itself.

09

Files

Everything is generated from marks.js by export.js, so a change to the drawing or a palette updates every file at once.
